WICS Installation Guide

Installation of nowRail and WICS add-on software to the ESP32 Microcontroller.

  • Installation of nowRail and WICS software deletes existing content on the Microcontroller.
  • If upgrading the software, please copy existing configuration files first from littleFS using ESP Connect.
  • Only install the software if you have the associated WICS Board (MCU and PIN dependent).
  • Espressif ESP32-S3 have Micro-USB, the other ESP32 models is using USB-C.
  • If you experience problems with "hanging or installation not starting", please set the Microcontroller into "Flash Mode" by holding down the right Boot button on the ESP32-C6/S3 (Gateway) and the left button on the ESP32-S3 (PCA9685) while powering up (connecting the USB cable) the Microcontroller.

Installation Steps:

  1. Connect the Microcontroller with a "real" USB-cable (not a charging cable) to the USB port on the Microcontroller.
  2. Select the WICS Board from the menu/submenu and click the "Connect".
  3. Follow the instructions on the screen.
  4. When done, Reboot the Microcontroller.
  5. Upload your configuration file using ESP-Connect.
